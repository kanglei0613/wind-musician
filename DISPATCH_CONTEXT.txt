## Windows 環境設定（下一步要做的事）

用戶要在 Windows 桌機設定自動提醒排程，步驟如下：

### 1. 安裝 Python
  https://www.python.org/downloads/
  安裝時勾選「Add Python to PATH」

### 2. Clone 專案
  git clone https://github.com/kanglei0613/wind-musician.git
  cd wind-musician

### 3. 安裝套件
  pip install -r requirements.txt

### 4. 建立 email_config.py（參考 email_config.example.py）
  複製 email_config.example.py → 重新命名為 email_config.py
  填入：
    GMAIL_ADDRESS  = "kla7522@gmail.com"
    GMAIL_APP_PASS = "jpmdfjaharce gcka"   ← Gmail 應用程式密碼
    （其他連結已填好，直接用 example 裡的值）

### 5. 複製以下兩個敏感檔案（從 Mac 複製或重新下載）
  - AuthKey_RWH3KB6P35.p8         ← App Store Connect API 金鑰
  - wind-musician-firebase-adminsdk-fbsvc-bc2f829d06.json  ← Firebase 服務帳戶金鑰

### 6. 測試腳本（dry run）
  python send_ios_reminder.py --dry-run
  python send_android_reminder.py --dry-run

### 7. 設定 Windows 工作排程器（Task Scheduler）
  目標：每5天自動執行 run_reminders.bat

  步驟：
  a. 開始 → 搜尋「工作排程器」→ 開啟
  b. 右側點「建立基本工作」
  c. 名稱：MuKlang 測試提醒
  d. 觸發程序：選「每天」→ 設定開始日期 2026-05-15（邀請後第5天）
                 進階設定：每隔 5 天重複
  e. 動作：「啟動程式」
     程式：C:\Windows\System32\cmd.exe
     引數：/c "C:\path\to\wind-musician\run_reminders.bat"
     （將 path 換成實際路徑）
  f. 完成儲存

## 腳本說明

| 檔案                        | 用途                                    |
|-----------------------------|-----------------------------------------|
| send_ios_reminder.py        | 查 TestFlight 未安裝者，寄 iOS 提醒信    |
| send_android_reminder.py    | 查 Firebase 未安裝者，寄 Android 提醒信  |
| check_ios_testers.py        | 查看 iOS 安裝狀態報告（手動用）          |
| check_android_testers.py    | 查看 Android 安裝狀態報告（手動用）      |
| run_reminders.bat           | 同時跑兩個提醒腳本（Windows 排程用）     |
| add_testers.py              | 批次加入 TestFlight 測試者（已完成）     |
| ios_emails.txt              | iOS 測試者 email 名單（gitignored）      |
| email_config.py             | Gmail 密碼等敏感設定（gitignored）       |
| ios_reminder_log.json       | 記錄 iOS 提醒寄送記錄（自動產生）        |
| android_reminder_log.json   | 記錄 Android 提醒寄送記錄（自動產生）   |
