2.2 狀態管理
────────────────
使用 flutter_riverpod 2.x（Riverpod 2）。
- StateNotifier    ← 調音器、錄音機等複雜業務邏輯
- StateProvider    ← 簡單 UI 狀態（日曆選中日期、Tab 選中等）
- StreamProvider   ← Firestore 即時資料（練習紀錄、樂團事件）
- FutureProvider   ← 非即時的 Firestore 查詢（用戶樂團列表）
- Provider         ← Repository 實例

Provider 注入路徑：
  Repository → Provider → StreamProvider.family → ConsumerWidget


2.3 路由
────────────
使用 go_router 14.x，所有頁面在 main.dart 的 GoRouter 中定義。
主要路由：
  /              → TunerPage（首頁，含節拍器和音叉 Tab）
  /recorder      → RecorderPage
  /calendar      → CalendarPage
  /analysis      → AnalysisPage
  /terminology   → TerminologyPage
  /guide         → UserGuidePage
  /subscription  → SubscriptionPage
  /login         → LoginPage
  /ensemble/:id  → EnsemblePage（樂團詳情）

3.1 調音器（TunerPage + TunerNotifier）
────────────────────────────────────────
位置：lib/features/tuner/
狀態管理：TunerNotifier（StateNotifier<TunerState>）

功能：
- 即時麥克風音高偵測（pitch_detector_dart，FFT 4096 sample）
- 顯示音名（C / C# / D 等）、音分誤差（cents）、頻率（Hz）
- 視覺指針：誤差 ±10 cents 內顯示綠色「準確」
- 可調音高基準：420 ~ 460 Hz（預設 A4=442 Hz，可 +/- 0.5Hz 微調）
- 樂器移調支援：C / Bb / Eb / F 調
- 週期：麥克風串流 → 緩衝 → PitchDetector → UI 刷新
- 連續 5 拍無訊號自動清除顯示（避免殘影）

樂器列表（含移調音名 Bb/Eb/F 自動換算）：
  長笛、雙簧管、英國管（舊稱：英國號→已修正）、
  降 Bb 單簧管、降 Eb 單簧管、低音單簧管、
  降 Bb 薩克斯風（soprano/alto/tenor/baritone）、
  小號、法國號、長號（B-flat/E-flat）、
  低音號（舊稱：大號→已修正）、打擊樂、豎琴、Concert Pitch

生命週期：
- App 切入背景（paused/inactive）→ stopListening()（節省電量）
- App 回到前景（resumed）→ startListening()（透過 WidgetsBindingObserver）

麥克風權限：
  首次使用請求權限。
  permanentlyDenied 時顯示提示並引導開啟系統設定。


3.2 節拍器（Metronome Widget）
────────────────────────────────────────
位置：lib/features/tuner/widgets/metronome.dart

功能：
- BPM 範圍：20 ~ 320（長按加速、點擊微調、點擊數字直接輸入）
- BPM 輸入防呆：數字鍵盤 + 超出範圍自動夾值並顯示 SnackBar 提示
- 拍號：分子 1~32，分母限 [1, 2, 4, 8, 16, 32]（正規音樂值）
- 段落模式（Section Mode）：最多 N 段，每段獨立拍號 + 小節數，循環播放
- 節拍動畫：圓點縮放 + 顏色變化（強拍 / 弱拍區分）
- 閃爍提示：段落切換時顯示段落標號

Android（已完成）：
  後台持續播放：Android 前景服務（MetronomeService）+ WakeLock
    → 即使切回桌面、鎖螢幕仍繼續準確播放
    → 通知欄顯示「節拍器運行中 · BPM · 拍號」，可點擊返回 App
  音訊引擎：HandlerThread(THREAD_PRIORITY_AUDIO) + AudioTrack(MODE_STATIC)
    → PCM 正弦波：強拍 880Hz、弱拍 660Hz
    → Attack/Decay Envelope：5ms 淡入 + 55ms 衰減，無爆音
  時間補償：SystemClock.elapsedRealtime() 絕對時間，每拍計算「應到時間 - 實際時間」
    → 消除 Handler.postDelayed 鏈式呼叫的累積漂移
  AudioFocus 管理：請求 AUDIOFOCUS_GAIN，監聽搶焦點事件
    → 來電 / 錄影工具搶走焦點時自動暫停並通知 Flutter UI

iOS（現有）：
  Dart Timer + SoLoud（flutter_soloud）
  時間補償：DateTime.now() 絕對時間（同樣消除漂移）
  後台播放：尚未實作（iOS 需 Background Audio 設定，未來版本）

Platform Channel 設計：
  名稱：com.kanglei.wind_musician/metronome
  Flutter → Native：start({bpm, numerator, denominator}) / stop / updateBpm / updateTimeSig
  Native → Flutter：invokeMethod("onBeat") → Flutter 更新 UI 動畫和段落邏輯

5.1 節拍器 Channel
────────────────────────────────────────
Channel 名稱：com.kanglei.wind_musician/metronome

Flutter → Native（MethodChannel invoke）：
  start({bpm: Int, numerator: Int, denominator: Int})
    → startForegroundService + MetronomeEngine.start()
  stop()
    → MetronomeEngine.stop() + abandonFocus + stopForeground
  updateBpm({bpm: Int})
    → MetronomeEngine.updateBpm()（不中斷播放）
  updateTimeSig({numerator: Int, denominator: Int})
    → MetronomeEngine.updateTimeSig()（段落切換時呼叫）

Native → Flutter（invokeMethod）：
  "onBeat"
    → Flutter 更新 _currentBeat + 動畫 + 段落邏輯

Flutter 側封裝：lib/shared/services/native_metronome_channel.dart（Singleton）


5.2 AudioFocus Channel
────────────────────────────────────────
Channel 名稱：com.kanglei.wind_musician/audio_focus

Native → Flutter（invokeMethod）：
  "onFocusChange" (args: Int)
    → 整數對應 AudioManager.AUDIOFOCUS_* 常數
    → Flutter 側 AudioFocusChannel 轉換為 AudioFocusState 枚舉並廣播

AudioFocusState 枚舉：
  gained         →  1   AUDIOFOCUS_GAIN
  lost           → -1   AUDIOFOCUS_LOSS（永久失去，例如音樂 App 啟動）
  lostTransient  → -2   AUDIOFOCUS_LOSS_TRANSIENT（短暫失去，例如來電）
  duck           → -3   AUDIOFOCUS_LOSS_TRANSIENT_CAN_DUCK（可壓低音量）

Flutter 處理策略：
  lost / lostTransient → 自動暫停節拍器 UI + 顯示 SnackBar「音訊焦點被其他 App 搶走」
  gained               → 不自動重啟，由用戶手動按播放
  duck                 → 保持播放（Native 不降音量，節拍器全音量繼續）

Flutter 側封裝：lib/shared/services/audio_focus_channel.dart（Singleton）


5.3 服務連線管理（MainActivity.kt）
────────────────────────────────────────
- onStart()：bindService()（Activity 進入前景時 bind）
- onStop()：unbindService()（Activity 離開前景時 unbind）
- onServiceConnected：設定 onBeatCallback + onAudioFocusChangeCallback

────────────────────────────────────────────────────────────────────────────────
六、Android 前景服務（MetronomeService）
────────────────────────────────────────────────────────────────────────────────

Manifest 宣告：
  android:foregroundServiceType="mediaPlayback"  ← Android 10+ 必須
  android:exported="false"

申請的 Permissions：
  FOREGROUND_SERVICE
  FOREGROUND_SERVICE_MEDIA_PLAYBACK
  WAKE_LOCK
  POST_NOTIFICATIONS   ← Android 13+ 通知需要
  RECORD_AUDIO
  INTERNET

MetronomeService 生命週期：
  起點：MainActivity.handleMetronomeCall("start") → startForegroundService()
  → onCreate()：建立 MetronomeEngine + AudioFocusHandler + NotificationChannel
  → startMetronome()：requestFocus → acquireWakeLock → startForeground → engine.start()
  → 節拍持續播放（HandlerThread 獨立執行緒）
  停點：stopMetronome()：engine.stop → abandonFocus → releaseWakeLock → stopForeground

WakeLock：
  類型：PARTIAL_WAKE_LOCK（CPU 運行，螢幕可關閉）
  最長持有：3 小時（防止意外洩漏）
  正常情況：stopMetronome() 時釋放

MetronomeEngine 核心：
  HandlerThread 優先級：Process.THREAD_PRIORITY_AUDIO
  AudioTrack：MODE_STATIC，PCM_16BIT，44100 Hz，Mono
  音色：正弦波，強拍 880Hz/0.85 峰值，弱拍 660Hz/0.55 峰值
  Envelope：5ms attack → 55ms decay → 靜音（共 100ms），消除爆音
  時間補償公式：
    intervalMs  = 60000 / bpm * (4 / denominator)
    targetMs    = beatIndex * intervalMs
    elapsedMs   = SystemClock.elapsedRealtime() - startElapsedMs
    delayMs     = clamp(targetMs - elapsedMs, 0, 2*intervalMs)

  ④ startRecording 缺少麥克風權限檢查 → 加入 permission_handler 請求流程
  ⑤ 調音器 permanentlyDenied 未處理 → 引導使用者至系統設定
  ⑥ 術語查詢語言寫死 'en' → 跟隨 App 語言設定
  ⑦ 節拍器長按 timer 未在 cancel 時停止 → GestureDetector.onLongPressCancel 補充

P2 UX 問題：
  ⑧ 儲存錄音空白名稱靜默失敗 → 顯示錯誤提示，要求輸入名稱
  ⑨ 練習紀錄刪除無確認 → 加入二次確認 AlertDialog
  ⑩ BPM 輸入無防呆 → 數字鍵盤 + 超出範圍夾值提示
  ⑪ 分母可輸入任意值 → 限制為 [1, 2, 4, 8, 16, 32]
  ⑫ 節拍器 Timer 累積漂移 → 絕對時間補償算法
  ⑬ 音叉/節拍器音訊爆音 → Fade-in/out envelope
  ⑭ 術語文字錯誤：大號→低音號、英國號→英國管

文字 / l10n：
  ⑮ app_localizations_ja.dart / ko.dart 有 null byte 汙染 → Python binary 修復
  ⑯ 語言設定不持久化 → SharedPreferences 儲存
  ⑰ ARB 缺少 metronomeBpmClamped / recorderSaveNameRequired key → 補齊四語言

九、環境建置與執行
────────────────────────────────────────────────────────────────────────────────

開發環境：
  Flutter SDK：^3.11.4
  Dart SDK：^3.11.4
  Android Studio / VS Code + Flutter Extension
  Android：minSdk = flutter.minSdkVersion（通常 21）
  iOS：最低 iOS 13（依 flutter default）

Firebase 設定步驟：
  1. Firebase Console 建立 Android App（package: com.kanglei.wind_musician）
  2. 下載 google-services.json → android/app/
  3. Firebase Console 建立 iOS App（Bundle ID: com.kanglei.windMusician）
  4. 下載 GoogleService-Info.plist → ios/Runner/
  5. Firebase Console 啟用 Authentication（Google + Apple + Email）
  6. Firebase Console 啟用 Firestore Database

執行指令：
  flutter pub get           # 安裝依賴
  flutter run               # Debug 模式（自動 gen-l10n）
  flutter run --release     # Release 模式
  flutter build apk         # 打包 Android APK（arm64-v8a）
  flutter build apk --split-per-abi   # 分架構 APK（較小）
  flutter build appbundle   # 打包 Android App Bundle（上架用）
  flutter build ios         # 打包 iOS（需 Xcode）

後端 API 開發模式：
  AppConstants.isDev = true 時 App 連 http://10.0.2.2:8000
  在電腦啟動 FastAPI：uvicorn main:app --reload --host 0.0.0.0 --port 8000
  Android 模擬器的 10.0.2.2 = 電腦的 localhost

通知權限（Android 13+）：
  首次使用前景服務時系統會彈出通知權限請求
  若用戶拒絕，前景服務仍可運行，但無通知欄顯示

十二、語系 ARB 關鍵 Key 清單（重要）
────────────────────────────────────────────────────────────────────────────────

新增語系 Key 的標準流程：
  1. 在 app_zh.arb 加入 key 和中文值（及 @metadata 如有 placeholder）
  2. 在 app_en.arb 加入英文值
  3. 在 app_ja.arb 加入日文值
  4. 在 app_ko.arb 加入韓文值
  5. flutter run（自動 gen-l10n）

有 Placeholder 的 Key 範例：
  "metronomeBpmClamped": "BPM 已自動調整為 {bpm}",
  "@metronomeBpmClamped": {
    "placeholders": {
      "bpm": { "type": "int" }
    }
  }

重要：不要直接在 app_localizations*.dart 改內容，flutter run 會覆蓋。
